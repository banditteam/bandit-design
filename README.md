# Bandit Mechanical Design

**Design it. Build it. Make it yours.**

Bandit Mechanical Design is the open-source design workspace for Bandit, a community-driven humanoid robotics platform.

The robot's appearance and mechanical design are yours to explore, modify, and improve.

Start with our editable Bandit model, create a new shell, experiment with hardware modifications, design components for 3D printing, or build your own version of Bandit.

**Your design could become the next Bandit.**

## What's Inside

- **Blender sources** — Editable Bandit design, geometry and materials.
- **Exploded view** — Development resources for visualizing Bandit's mechanical components and hardware.
- **Mechanical design** — A workspace for future CAD models, actuators, mounting systems and hardware upgrades.
- **3D printing** — A home for printable prototypes and community-created parts.
- **Documentation** — Design references, dimensions, compatibility notes and contribution guidelines.

Some sections are planned and will be populated as development progresses.

## Get Started

Clone this repository:

```bash
git lfs install
git clone https://github.com/banditteam/bandit-mechanical-design.git
```

Open the Blender source file and start designing.

Git LFS is required to retrieve large source files stored through LFS.

## What Can You Contribute?

Redesign Bandit's head, shell or body panels. Create mounting brackets, articulated components, sensor housings, custom tails or entirely new mechanical concepts.

We welcome editable Blender and CAD sources, STL models, GLB previews, design proposals and documented prototypes.

Please include source files, dimensions, screenshots and compatibility notes where applicable.

Design concepts should be distinguished from mechanically validated, manufacturing-ready parts.

## From Design to Simulation

Your mechanical design can become part of a working robot.

**[Bandit Description](https://github.com/banditteam/bandit-description)** provides the URDF, meshes and robot structure for simulation.

**[Bandit Robotics](https://github.com/banditteam/bandit-robotics)** provides the simulation environment, examples and robotics development tools.

Update the robot description to integrate new geometry, joints or hardware, then test your changes in simulation.

## Community Contributions

Fork the repository, create your design or improvement, document what changed and submit a pull request.

We encourage experimentation, reproducible designs and open collaboration.
